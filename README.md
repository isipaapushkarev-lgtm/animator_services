# ЯРКО Night Show

Учебное веб-приложение по теме «Услуги аниматоров».

## Запуск в XAMPP

1. Импортировать `database/schema.sql` в phpMyAdmin.
2. Скопировать проект в `C:\xampp\htdocs\lr3`.
3. Открыть `http://localhost/lr3/`.

Подключение к MySQL задаётся в `config.php`. Для стандартного XAMPP используются пользователь `root` и пустой пароль.
При необходимости нестандартный порт MySQL можно передать через переменную окружения `YARKO_DB_PORT`; без неё используется порт `3306`.

## Учётные записи

- Клиент: `anna@example.ru`, пароль `Admin123!`.

## Возможности

- 9 адаптивных страниц по плану темы;
- регистрация, вход, выход и серверная валидация;
- оформление заказа и получение номера заявки;
- личный кабинет с заказами и загрузкой фотографий;
- отзывы к завершённым заказам;
- административная панель с CRUD для 7 таблиц и просмотром 5 представлений;
- интерактивная карта Leaflet с данными OpenStreetMap.
